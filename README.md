# mod-lab

个人逆向与魔改实验台：APK 分析、固件/硬件调试、LSPosed 模块与脚本，以及公开可复用的工具笔记。

## 目录约定

| 目录 | 内容 |
| --- | --- |
| `apk/` | 自有应用的改包记录、patch 说明、签名处理笔记 |
| `firmware/` | 固件分析笔记、分区表、备份与刷写脚本 |
| `modules/` | 自写 LSPosed / Magisk 模块源码与构建说明 |
| `scripts/` | 调试、批量处理、日志分析等辅助脚本 |
| `notes/` | 设备、芯片、平台踩坑记录（sun8iw11p1 / R40 / AXP209 等） |
| `assets/` | 截图、串口/示波器日志、实测数据 |

## 原则

- 只记录自有设备与自有软件上的操作。
- 引用的第三方开源项目保留原作者署名与许可证，不抹除版权信息。
- 大文件（固件、安装包等）走 Release 附件，不直接塞进 git 历史。
